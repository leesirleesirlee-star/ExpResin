## 2. 柱实验穿透曲线

前端新增/修正：

- `src/domain/curveData.js`：新增 C₀ 元数据解析、单位换算、样品行过滤、C/C₀ 序列构建、阈值线性插值与穿透/饱和摘要；保留原有数值列与刻度函数。
- `src/components/CurveBuilder.vue`：模块改为穿透曲线；实验选择、BV/mL 横轴、C/C₀ 或出口浓度纵轴、C₀ 输入、分析物/数据区/区域分组、5%/10% 阈值、穿透/饱和指标卡、阈值线与交点。
- `HomeView.vue`：模块名称改为「穿透曲线」，副标题为「柱实验 C/C₀ 与穿透点」。
- 指标卡按分组显示：穿透点、饱和点（固定 95%）、最高 C/C₀；未达到阈值时明确显示「未达到」。

功能边界：

- 读取 `GET /v1/experiments/{id}/data/canonical` 和 `GET /v1/experiments/{id}`；只使用当前账号本人档案。
- 只取 `kind = sample_measurement` 的行；`kind = calibration` 的标定标准行单独计数并排除，避免把标定点画成穿透曲线。
- 出口浓度优先使用引擎反算值，缺失时回退报告值；C₀ 优先读实验元数据，缺失时回退规范表容量计算，再缺失才要求手动填写。
- 横轴接受床体积 BV、流出体积 mL，或规范行已提供的时间列（min/h）；都没有时明确提示，不使用行号代替。
- 穿透点按 5%/10% 阈值、饱和点按 95%，在相邻样品之间线性插值；阈值未达到时不伪造交点。
- 最多同时显示 8 组曲线；超过 120 个点时隐藏普通点标记，阈值交点仍保留。
- 导出 SVG（矢量）、PNG（2× 白底画布）、CSV（`series,x,出口浓度,C/C0`）；SVG 的颜色与文字使用内联属性，脱离页面 CSS 仍可打开。
- 图表为白色科学绘图区，深色主题下也不反色；该偏离已写入 `docs/design/design-changelog.md` §29。

## 3. 可靠性与性能维护

- 修复 `dev.ps1` 依赖 `Get-NetTCPConnection` 导致的误判：改为 HTTP + 进程命令行识别，`start/status/stop` 实测可用。
- 新增 `backend.ps1`：解析 `sys.executable`，避免 WindowsApps 代理留下父子双进程；健康检查作为唯一就绪标准。
- API 默认超时 20 秒，启动鉴权 8 秒；超时覆盖响应体读取阶段。
- 聊天打字机改为增量追加；滚动用 `requestAnimationFrame` 合并，用户上滚后不再强制拉回底部。
- 上传限制 50 MB；文件名去除目录片段并限制字符集；同名不同内容用 sha 前缀保留多版本。
- 上传解析移入线程池，避免阻塞 health、登录及其他请求；无规范数据时保持明确错误。
- 修复 SQLite 共享连接并发错误：原 `check_same_thread=False` 单连接被 FastAPI 线程池同时使用，登录鉴权会偶发 `sqlite3.InterfaceError`。现改为 WAL + 每线程独立连接 + 30 秒 busy timeout，并以事务回滚测试确认批量草稿写入的原子性。
